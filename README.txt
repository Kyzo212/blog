Deploy (pick one)
  Netlify:      go to app.netlify.com/drop and drag this whole folder in.
  GitHub Pages: push the folder contents to a repo, then Settings > Pages > deploy from main branch, root.
  Vercel:       import the repo or run "vercel" inside the folder.

Submit the URL of each post page, for example:
  https://YOUR-SITE/posts/auditors-view.html
